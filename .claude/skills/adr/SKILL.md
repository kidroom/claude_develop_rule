# 建立 ADR

## 步驟
1. `docs/adr/` 不存在就建立，並建立 `_template.md`，欄位：標題、日期、狀態、背景、決定、考慮過的方案、後果、對 AI 開發的提示。
2. 編號為現有最大流水號加 1，四位數補零。
3. 確認三件事：背景、決定、放棄的方案與原因；已說清楚的不重問。
4. 寫入 `docs/adr/NNNN-<kebab-case 標題>.md`，日期為今天，狀態為「已採納」；一頁內寫完。
5. 「對 AI 開發的提示」寫明：什麼情況應遵循此決策，而不是把它當成錯誤修正。
6. 屬於規範例外者，在 `CLAUDE.md` 的已知落差表加一列指向此 ADR。
7. 涉及 MUST 例外（依賴方向、feature flag、資料庫分階段變更、重試策略、契約 breaking change）須寫明補償措施與回退方案。

## 狀態
- 已採納 → 被新決策取代時改為「已取代（見 NNNN）」，不刪除舊 ADR。
