# 安全重構

規則依 `.claude/rules/refactoring.md`；本 skill 提供執行步驟。

## 1. 確認可以開始
依 `refactoring.md` 確認：不屬於禁止或暫緩情境、目的明確、有測試保護（沒有就先寫特性測試並 commit）；不符合就停止並回報。

## 2. 說明範圍並等待確認
列出：目的、要改的檔案、要處理的壞味道與手法（對照 [code-smells.md](code-smells.md)）、是否動到公開介面。
動到被多處使用的函式或介面，或預計超過一個 PR 時，依 [large-refactoring.md](large-refactoring.md) 選擇策略。

## 3. 安全循環
1. 只執行一種重構手法，優先用 IDE 或工具的自動重構。
2. 執行測試。
3. 綠燈 → commit（`refactor: ...`），進行下一個手法。
4. 紅燈且無法立即修正 → 捨棄本步驟未提交的變更，以更小步驟重來。

## 4. 回報
- 每個步驟使用的手法與實際測試結果。
- 範圍外看到但沒處理的問題。
