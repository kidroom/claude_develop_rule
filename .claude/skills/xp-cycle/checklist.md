# 提交前檢查表

逐項確認；任一項不成立即停止並回報。不適用的項目標「不適用」並說明。

## 動手前
- [ ] 已讀受影響檔案與所有呼叫端，影響範圍已列出；觸及影響分析項目者已附 `/impact-analysis` 結果
- [ ] 本次變更屬於重構或功能其中之一，沒有混合
- [ ] 沒有測試覆蓋的既有程式碼已補特性測試
- [ ] 計畫已取得使用者確認

## 設計
- [ ] 依賴方向正確；跨層只透過介面（`architecture.md`）
- [ ] 封裝完整：狀態只經行為方法變更，不變條件在建構時強制（`design-principles.md`）
- [ ] 已有擴充點時，新增行為靠新增程式碼，沒有改既有分支或函式語意
- [ ] 沒有過度設計警訊，也沒有在確定的變化方向上堆疊 if-else（`simple-design.md`）
- [ ] 沒有引入禁用模式

## 程式碼
- [ ] 命名、函式長度、參數數量、巢狀深度符合 `coding.md`；沒有魔術數字與布林旗標參數
- [ ] null 安全檢查沒有被強制抑制；資料載體不可變、公開集合唯讀（`design-principles.md`）

## 行為安全
- [ ] 業務邏輯沒有 I/O；時間、ID、設定皆為注入；沒有可變的全域狀態（`reliability.md`）
- [ ] 預期失敗回傳結果型別；沒有空 catch
- [ ] 非同步到底、傳遞取消訊號；沒有同步等待或 fire-and-forget
- [ ] 查詢有投影與上限；一個用例一個交易，交易內沒有外部呼叫
- [ ] 資料庫變更依 Expand／Contract；對外契約沒有 breaking change，或已有遷移計畫（`api-and-database.md`）
- [ ] 外部呼叫有逾時與明確的失敗策略；副作用操作支援冪等

## 交付
- [ ] 影響既有行為的變更在 feature flag 後（`change-and-release.md`）
- [ ] 設定鍵有增減時，各環境設定檔、本機範本、部署腳本與文件已同步
- [ ] 新增了失敗路徑的測試；修 bug 有重現測試
- [ ] 日誌沒有敏感資料；沒有秘密進版控（`security.md`）
- [ ] 建置、lint、測試已實際執行並如實回報結果（含失敗與未執行項目）
- [ ] PR 描述五項齊備，沒有夾帶無關變更
