# 安全規範

| 項目 | 執行規範 |
|---|---|
| 輸入驗證 | 所有外部輸入（HTTP、檔案、訊息佇列、環境變數）在邊界驗證型別、格式、範圍與長度；用允許清單，不用阻擋清單 |
| 注入防護 | SQL 一律參數化；不以字串串接組合查詢、shell 命令、HTML 或檔案路徑 |
| 輸出編碼 | 輸出到 HTML、URL、日誌時依情境跳脫 |
| 認證 | 不自製加密或雜湊演算法，使用成熟函式庫；密碼以專用演算法（bcrypt、Argon2）雜湊儲存 |
| 授權 | 每個操作都在伺服器端檢查權限，預設拒絕；不依賴前端隱藏 |
| 秘密管理 | 只從環境變數或秘密管理服務讀取；不寫進程式碼、測試、日誌、錯誤訊息或版控（寫入檔案與 commit 前由 hook 掃描；測試假值須用明顯的佔位符） |
| 設定檔 | 進版控的設定檔中，秘密與連線欄位一律留空，值放未納入版控的本機檔或環境變數；提交前確認暫存區沒有含值的設定檔 |
| 敏感資料 | 日誌與錯誤回應不含密碼、token、完整卡號或個資，必要時遮罩；對外錯誤不暴露堆疊、連線字串與內部結構 |
| 最小權限 | 服務帳號、資料庫帳號、token 只給完成任務所需的權限 |
| 傳輸 | 對外連線使用 TLS；不關閉憑證驗證 |

相依套件的漏洞檢查見 `coding.md` 與 `tooling-ci.md`。發現疑似安全問題（包含既有程式碼）時立即回報，不自行判斷可以忽略。
